# Exergaming Motor Data Acquisition
A demo made for the Laboratory of Wearables and Mobile Health exam in 2023 (Biomedical Engineering MS in Neuroscience), showcasing motor data acquisition in a game environment during physical exercise (Exergaming), through a self-developed recognition algorithm of discrete motion skills &mdash; namely walking, running, jumping, and squatting.

The project's demo and further information are available in `Exergaming Project.pptx`, along with a video demonstration.
