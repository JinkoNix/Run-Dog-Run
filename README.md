# Exergaming Motor Data Acquisition
A demo made for the Laboratory of Wearables and Mobile Health exam in 2023 (Biomedical Engineering MS in Neuroscience), showcasing motor data acquisition in a game environment during physical exercise (Exergaming), through a self-developed recognition algorithm of discrete motion skills: Walk, Run, Jump, and Squat.

Input signals, such as gyroscope and accelerometer data, are provided through a Bluetooth connection of the user's personal phone, which is held inside the pocket for the whole duration of the acquisition. Personal data are then saved locally to avoid online data breaches, and can be later read and analyzed through an ad-hoc MATLAB script.

The project's demo and further information are available in `Exergaming Project.pptx`, along with a video demonstration.
